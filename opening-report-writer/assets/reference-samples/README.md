# 参考范本目录｜仅学习体裁，不是官方模板

本目录参考 `thesis-midterm-check-write-v1.3` 的 A/B/C/D 清单管理方式，**当前实际收录一份**最初用户提供、去标识化的完整已填写开题报告。原始个人信息文件不进入 Skill 压缩包。

| 编号 | 文件 | 用途 |
|---|---|---|
| SAMPLE-A | `sample-a-smart-interaction-anonymized.docx` | 学习背景→目的→现状→任务与可行性→难点→条件→方案与周计划→文献的连贯铺陈；不学习原项目事实 |

- `samples-manifest.json`：样本的身份、作用、SHA256、禁止事项。
- `SAMPLE-A.sha256`：锁定脱敏版文件字节；更新样本必须重新审计、更新清单并运行回归测试。
- **每次先读官方空白模板** `../official-opening-report-template.docx`；只有在了解不可改的固定结构后才参考这里的匿名范本。
- 初始范本内可能存在过时周次、未经本次核实的文献和技术数字，以及与本轮七章预设不同的分节名称。这些不具有规范效力。
- 不得调用 `scripts/build_report.py --template` 指向本目录的任何样本。
- 如未来增加第二份、第三份已填范本，应逐份脱敏、记录独立哈希，重新审查 Word 属性和正文敏感信息；不能直接打包原稿。
