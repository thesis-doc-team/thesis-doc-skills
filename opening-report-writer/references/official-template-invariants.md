# 官方 Word 模板逆向结构与不可变约束

> **唯一正式模板**：`assets/official-opening-report-template.docx`，源于用户上传的《02_塔里木大学毕业论文（设计）开题报告.docx》。本文为模板逆向结果，不是对官方规定的修改。文件名规范化仅用于 Skill 内部引用，二进制内容完全相同；校验值见 `assets/template.sha256`。

## 1. 实测结构（不是凭示例文档推断）

| 项目 | 官方模板原件读出的实际属性 |
|---|---|
| 文件类型 | DOCX / OOXML |
| 页面 | A4 纵向，约 210 × 297 mm |
| 页边距 | 上 37.006 mm；下 25.206 mm；左 27.993 mm；右 25.999 mm |
| 节 | 1 个 Section |
| 正文主体 | 1 个 Word 表格，2 行 × 1 列，`Table Grid` 样式 |
| 第一行 | 开头是《开题报告正文》及字体/行距说明；后接约 61 个空白书写段落；末尾固定学生签名、日期 |
| 第二行 | “指导教师审阅意见：（不少于50字）”；供教师书写的空白段落；教师签名与日期 |
| 填写说明 | 封面之后，明确七项内容、文献不少于 10 篇、正文不少于 3000 字、签字须手写 |
| 模板自身说明 | 正文五号宋体、1.5 倍行距；英文、罗马字符 Times New Roman 正体 |
| 官方模板页数 | 当前空白原件可呈现为 4 页（不同 Word/WPS 环境可能有差异） |

**注意**：官方模板的正文书写区实际上**没有**预置“1/1.1/2”等七章标题。七项研究内容来自填写说明；Skill 提供统一默认标题供新写入内容使用，但不能谎称章题是学校原件固定文字。

## 2. 三类内容的界线

| 类型 | 例子 | 处理方式 |
|---|---|---|
| 绝对不可修改的官方结构 | 学校名称、标题、附件 2 标记、教务处制、填写说明、正文要求提示、表格边框、签字及日期区域、页码和页面节属性 | 完全保留，不得格式化/删除/覆盖 |
| 用户授权填写的字段 | 题目、姓名、学号、学院、专业、班级、导师、职称、起止时间 | 只替换原字段的空白下划线占位内容，保留字段名/段落属性/字体/下划线 |
| 用户授权书写的正文区域 | 第一行表格提示之后、学生签名之前的空白段落 | 只在这里填入七项研究内容；留白段落可被内容占用，冗余空白占位可清除；不可改动同一表格的固定提示/签名/第二行 |

若用户将“不能更改任何地方”理解为连**生成副本中的可填写空白段落**也不允许调整，应先说明：在纯追加条件下不可能获得正常的连续正文，选择由用户确认；不得私自移动任何固定结构。默认按“禁止更改官方固定内容、仅填报授权空白区域”执行。

## 3. 不允许为了视觉效果而做的事

- 不用另建 DOCX 再把视觉设置抄过去；必须从本文件的副本开始。
- 不添加新的学校抬头、全新封面或替换原有签字栏。
- 不变更表格的边框、宽度、单元格数量、行属性。
- 不变更 `sectPr`、`styles.xml`、`numbering.xml`、字体定义、页眉页脚等 OOXML 包内固定部件。
- 不删除《填写说明》的规定、不改其措辞；其中原有空格甚至小的格式不统一也原样保留。
- 不从历史范本复制人物姓名、学号和导师信息。
- 禁止为了避免末页签名分离而调小页边距或偷偷删签字区。

## 4. 模板指纹和双层审查

### 静态审查

运行 `scripts/build_report.py` 前，校验本地官方模板 SHA256。生成器直接在源 DOCX 的 ZIP 各成员上做低层 Word XML 填充，**仅允许 `word/document.xml` 出现变化**，而且只允许封面字段空白文本及正文书写区。`scripts/check_report.py` 再逐项核对：

1. 其他 ZIP 成员内容逐字节相等；
2. 固定段落及《填写说明》没有变化；
3. 官方表格仍 2×1，第二行教师意见与签字 XML 完全相同；
4. 第一行开题正文提示和学生签名日期 XML 完全相同；
5. 页边距、节信息没有变化。

### 视觉审查

静态检查 PASS 不等于打印效果 PASS。实际完成 Word 后应渲染整篇，逐页观察文字溢出、边框延伸、字体替换、参考文献跨页、孤立标题、学生签字和教师签字是否被分页隔开。`签字栏孤立`属于不可交付的视觉问题，优先改变**新写入的正文**章节措辞或内容体量让分页自然落位，不能改签字栏本身。

## 5. 与其他开题范本的关系

新增一份已填写历史开题报告的**脱敏参考副本** `assets/reference-samples/sample-a-smart-interaction-anonymized.docx`，其唯一作用是展示写作展开和篇幅，不与本节所述空白官方模板混用。完整行为规范见 `references/anonymized-sample-usage.md`。

历史上曾提供六份已填写开题报告（可用于研究常见二级章题、正文论证方法和参考文献排法）。它们不是此官方文件的替代品：

1. 当前官方模板与用户当次明确要求优先；
2. 旧范本中出现比例较高且不与官方冲突的写法可以作为非强制建议；
3. 旧范本含错误的引用字段、重复编号、凭空市场数据、特殊行距，不得照搬；
4. 如两份范本出现不同章节名称，而官方只规定七项主题，则七项主题必须齐全，章题使用本 Skill 默认预设；不能说章题由学校指定。
