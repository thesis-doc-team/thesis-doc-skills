# SAMPLE A｜场地环境监测终端的工程推导

## 输入功能（匿名化）
温湿度、粉尘、风况、本地显示、远程上报、异常告警、系统运行状态。

## 可复用推导方法

1. 先问“测什么物理量、告警谁、安装在哪里、需要多长时间刷新”，再选择总线与传感器；不能见到“环境监测”便擅加土壤、火焰、CO₂。
2. 比较数字温湿度、主动串口粉尘、RS485/Modbus 工业风速的信号形式，形成 UART/I²C/ADC/GPIO 资源表；在资源满足时才选成本合适的 MCU。
3. 通信若有成熟 4G DTU，核对它实际是否支持 MQTT/TLS 和接入服务；MCU 不必重复实现完整蜂窝协议栈。
4. 对本地报警、周期上报和显示设计同一份带有效性与更新时间的数据契约。
5. 验收先独立传感器，再协议透传，再异常、掉线与安全边界；不把成功调用 UART 发送函数认定为远程平台接收。

## 禁止迁移

不迁移示例里的风速型号、I²C 地址、数据间隔、火警有效性、通信套餐或实体硬件已投入使用的事实。
