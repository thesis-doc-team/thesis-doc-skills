# SAMPLE B｜可穿戴人体运动检测终端的工程推导

## 需求歧义的关键示范

“人体检测”可能是区域存在、运动/姿态/摔倒或视觉人体识别。**先明确目标行为，再定传感器。** 不能因为名称含“人体”就直接选毫米波模块。

## 可复用推导方法

- 目标为行走、步数、摔倒时，从加速度/角速度/姿态角变化推导惯性测量路线，按需复用芯片内的姿态处理能力和成熟驱动。
- 业务层以 `姿态输入→轻量状态机→步数/行走/摔倒输出` 实现，阈值、持续确认和恢复条件必须结合佩戴位置与实测数据校准。
- 传感器数据访问接口、业务算法、OLED 显示、蜂鸣器、云通信分别负责各自职责。
- 无实物时 Mock 可以注入传感器数据；**直接给业务输出填“摔倒”只验证下游联动，不能证明真实算法准确。**

## 核对表

佩戴方式是否固定、摔倒定义、误报后果、采样率、DMP 数据正确性、算法测试输入集、告警复位与掉电行为。
