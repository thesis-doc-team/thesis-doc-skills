# 匿名化工程案例｜仅用于反向学习方法

**重要：下面的 A/B/C/D 都是从过往案例抽象出的“功能→设计决策→接口/数据流→验证”的结构样例，不是当前项目的素材库。**

| 样例 | 类型 | 参考重点 |
|---|---|---|
| A | 低功耗/场地环境安全监测 | 资源先行，成熟 DTU，传感器接口选择与本地报警 |
| B | 可穿戴运动/姿态检测 | 功能歧义、惯性传感器 DMP、轻量算法状态机、Mock 边界 |
| C | 双向 LoRa 环境节点 | 对端数据流、UART 收发、文本协议兼容、显示与有效性 |
| D | 智能交互终端 | Linux 前后端、语音唤醒会话、AI 动作、TTS/音乐音频焦点与进程健康 |
| HTML 视觉参考 | 仓储货架项目介绍页 | 配色、卡片、暗色场景面板、响应式断点与展示结构；**只参考样式方法，不复制其 4 货位业务数据** |
| Word 版式参考 C | 候选项目概览 DOCX | A4 杂志编辑版式、暖橙点缀、2 列概述条、3 列功能表；**只参考排版，不复制其老人拐杖业务数据** |

`candidate-overview-reference-C.docx` 是用户确认满意的候选 Word 版式参考；运行时由 `render_candidate.make_docx` 按规格生成，不把示例 DOCX 当作模板、也不复制其业务文字。

`project-introduction-reference.html` 是用户认可的页面样式参考，保留原样用于视觉回归；通用模板是 `templates/project-introduction.html`，不得把参考页的仓储专属内容（四个货位、重量/数量示例等）固化进通用模板。示例中的业务数值只作为演示数据，生成其他项目时必须由该项目的介绍 MD 重新映射。

每个案例只写“推导方法与检验点”，不携带具体人员、学校、设备密钥、云端地址、原始源码、图片和完整业务资料；不能把案例中的 MCU 型号、周期、阈值、接口当成新项目默认事实。**不能拿旧项目的不完善之处作为最佳实践**。本 Skill 会生成候选项目概览 DOCX（C 版版式）与正式 Markdown/HTML；没有官方 Word 模板锁。
