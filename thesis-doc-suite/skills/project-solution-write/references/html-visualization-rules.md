# 项目介绍 HTML 视觉规范（从参考示例逆向）

## 一、目标

把用户认可的项目介绍页面提炼为**固定视觉语言**：以后不同项目共用同一套配色、卡片、排版、暗色示意面板和响应式断点，但内容、功能数量、流程步骤、场景和术语完全来自各自的《项目介绍与功能说明.md》。不允许每个新项目重新设计一套视觉，也不允许把示例项目的仓储业务内容固化进模板。

参考文件：

- 视觉参考：`assets/reference-samples/project-introduction-reference.html`（用户提供的仓储示例，保留原样，仅作样式与结构参考）
- 通用模板：`templates/project-introduction.html`
- 生成器：`scripts/generate_intro_html.py`

## 三、页面骨架

```text
sticky header（品牌 / 章节导航 / 文档版本）
hero（项目类别 + 大标题 + 简介 + 按钮 + 关键词 + 概念面板）
summary（3–4 个项目特点卡片）
features（功能卡片，数量动态）
workflow（使用流程，数量动态）
showcase（暗色场景示意面板 + 场景切换）
scenes（应用场景卡片，数量动态）
composition（系统组成概览 + 标签）
footer（项目全称 + 内容来源/未实测声明）
```

- 页面最大宽度 1160px；桌面端留白充足，内容密度中等。
- 每个一级区块 `padding:55px 0`；hero 顶部 79px。
- 章节标题使用短 kicker（英文大写）+ 中文大标题 + 一句说明，保持示例的层级。
- header 高 76px，滚动时吸顶；导航只列出实际存在的区块，避免空锚点。

## 四、组件规则

1. **卡片**：白底、1px 浅边框、22px 圆角、轻阴影；hover 上浮 4px 并加深阴影。功能卡、流程卡、场景卡、summary 卡统一。
2. **色调**：每个卡片用 `tone-blue / tone-mint / tone-warm / tone-violet` 四色循环；不按项目类型随意换色。图标底色与卡片色调一致。
3. **图标**：只使用模板内置的固定 SVG 图形集（scale/layers/monitor/bell/radio/database/activity/cpu/cloud/shield/clock/spark/box），由功能标题关键词选择；不联网搜图、不使用 emoji 代替主要图标。
4. **概念面板**：hero 右侧是“项目概念图”，不是实时设备读数。面板顶部标注“概念展示”；tile 显示功能编号、功能名、简述和装饰进度条，进度条不代表真实数据。
5. **浮动标签**：桌面端保留 1–2 个浮动标签，文字来自功能标题（如“缺货报警”“无线通信”）；500px 以下隐藏，避免遮挡面板文字。
6. **暗色示意面板**：沿用深蓝底、圆角、屏幕边框、状态徽章、装饰进度条；只用于“验收场景/预期结果”，并固定标注“验收场景 · 预期结果 · 未实测”。
7. **场景切换**：按钮使用 `aria-pressed`，点击更新屏幕标题、编号、状态、操作、预期；无 JavaScript 时默认显示第一条场景，内容仍可读。
8. **按钮**：只保留真实可用的锚点跳转；不生成点击无反应的装饰按钮。主按钮蓝底、次按钮白底描边。
9. **长文本**：所有容器 `min-width:0`；标题、正文、卡片、芯片使用 `overflow-wrap:anywhere`；标题不使用 `white-space:nowrap`。
10. **响应式**：桌面 3 列功能卡；1000px 以下 hero 单列、流程 3 列；750px 以下功能 2 列、场景单列；500px 以下功能/摘要/流程单列，概念面板 2x2，隐藏浮动标签。禁止横向溢出。

## 五、动效与可访问性

- 滚动淡入使用 `.rise`；由 JavaScript 给 `<html>` 加 `js-ready` 后才隐藏初始状态，JS 失败时内容仍可见。
- `prefers-reduced-motion:reduce` 下关闭动画。
- 所有交互控件可键盘聚焦；焦点样式保留 3px 蓝色 outline。
- 图标 `aria-hidden="true"`；场景切换区 `role="status" aria-live="polite"`。
- 打印时隐藏导航、按钮、选择器与浮动标签；卡片避免跨页拆分。

## 六、不要做的事

- 不要把示例的“4 个货位”“24 件”“60.0 kg”等业务数据写进通用模板。
- 不要为不同项目更换配色体系或另写一套 CSS。
- 不要用虚构数值填充概念面板或场景示意；没有数据就用功能名、场景名或状态文字。
- 不要引入远程字体、图标、图片、脚本或 iframe。
- 不要把《工程实施方案》的引脚、协议、代码、部署命令带进页面。
- 不要为了视觉效果牺牲可读性；长标题、长描述、10+ 功能卡必须能正常换行和换行排布。
