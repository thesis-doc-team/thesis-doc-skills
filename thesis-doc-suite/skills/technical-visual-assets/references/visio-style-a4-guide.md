## 统一图形语言（对齐 Visio / 学术技术报告）

1. **可读性优先**：底色白；文字黑/深灰；普通节点使用无填充矩形、开始/结束可用圆角矩形，判断使用菱形，分区使用浅黑虚线框。不要默认彩虹色、渐变、重阴影、花哨图标。
2. **连线规则**：主线尽量左→右或上→下，箭头头部明确；判断两边标“是/否”或相应的实际条件；返回支线尽量绕开文字。交叉不可避免时通过跳线/分区重排解决，不能让图看起来变成另一条技术连接。
3. **对齐与留白**：同级节点宽高统一；节点之间不能贴边；虚线分区框内保留 4–8mm 文字留白；大图不要留 40% 以上毫无意义空白。
4. **字体与线条**：以最终插入 DOCX 后 9–10.5pt 为目标。中文优先宋体/与模板兼容字体，渲染过程使用可用的 CJK 字体回退。边框/箭头参考 0.35–0.5mm 视觉量级；图中文字若比正文小到难辨识则拒绝。
5. **原始可编辑文件优先**：Mermaid `.mmd`（语义文本）、显式布局 `.json`、可编辑 `.drawio`，渲染输出 `.svg`；需要 PNG 时使用已有可靠转换器按最终尺寸高质量输出，不假装 `.drawio` 就是 `.vsdx`。
6. **图题独立**：图片内部不包含“图 3-1 ...”标题；编号由 Word 业务 Skill 根据论文真实章节生成，文字另作居中段落。
7. **真正 A4 不是固定 210mm 图片**：所在官方模板 `pgSz - 左右页边距` 才是可用宽度。先调用 `a4_layout.py profile`。若模版 A4 页边距左右各 25mm → 正文宽 160mm。图片宽度不超过此值，图高还要扣图题及上下文。

## 表格强约束

- 以 R03 为参考：表题在表格上方或按学校范本位置，居中、完整，不让表题孤立在上一页；**所有新生成数据表一律严格三线表（强制）**，无竖线及额外内部横线；固定官方表单不改，冲突则报告 BLOCK。
- **Word 原生三线表**为强制要求：表顶横线、表头下横线、表底横线，三条且只有三条；不得存在竖线、内部行分隔线，不得将数据表格截图。
- **Word 原生表格**必须：可编辑、可选中文本、分页可控。含多列的技术对比表严格保留实际参数，绝不为了排版篡改性能结论。
- 所有列宽总和必须 ≤ 所在节正文宽；如 6 列以上且无法以 ≥9pt 清晰展示，考虑纵向内容重排或分成多张关联表，重复关键列；先检查官方模板允许这种拆分。
- 允许表格跨多页时保留重复表头、内容完整且行不被无意断开；不擅自变更标题层级、行距和参考文献格式。

## 图像放入 Word 前后双重验收

前：检查 SVG 实际尺寸、节点标签、箭头、字体，利用 `fit-figure` 计算是否必须重新布局；对于单张图宽高超标，自动降低展示尺寸造成文字小于 9pt 时一律 FAIL。

后：检查 DOCX 的 page sectPr、inline 图尺寸、原生表 grid 宽，再实际渲染每一相关页核对 WPS/Word 的裁剪、分页、遮挡、空白、图题和边框。这是强制人工验收，不可只用 XML 代替。

## 三线表可执行验收

文书写作 Skill 应在 Word 生成完毕后对**新生成数据表的具体索引**运行 `scripts/three_line_table.py audit --docx ... --indices ...`。BLOCK 不得交付为合格成品。必要时先对该数据表生成 `apply` 输出修订副本，再进行 Word/WPS 渲染验证。官方固定表单不可因审计而修改。

# v1.4.0 补充：正交连线与中英文图题

## 正交连线（强制）

- 常规连接线只能是水平线、垂直线或 90° 折线；不得默认输出斜线。
- 判断节点分支标签必须成对出现并靠近对应线段；同一判断的分支方向要稳定。
- 连线必须避开节点、节点文字和分区标签；回环从外侧绕行。
- 具体锚点、A* 路由、交叉/重叠惩罚和 QC 规则见 `references/orthogonal-routing-rules.md`。
- 失败样本与修订样本：`examples/before-diagonal-sms-flow-300dpi.png`、`examples/after-orthogonal-sms-flow-300dpi.png`、`examples/orthogonal-upgrade-comparison.png`。

## 中英文图题（强制）

- 每张正式图必须有 `figure_number`（如 `4-1`）、`caption_zh`、`caption_en`、`source_refs`。
- 图题放在图下、居中，由 Word 原生段落渲染；**不得画进 SVG/PNG 像素**。
- 英文题名必须描述实际内容，禁止只用 `Flowchart` / `System Diagram`。
- 元数据 schema、编号规则、Word 呈现和常见错误见 `references/english-caption-spec.md`。
- 真实 Word 渲染样例：`examples/A4-正交流程图与英文图题示例.docx` 与 `examples/page-1.png`。

## 重新理解七张参考图

- R01/R05/R07 的共同点不是“框好看”，而是：主链方向明确、所有折线 90°、分支标签贴近线段、图题在图下居中。
- R04 的分区框说明：分区标签本身也是障碍，连线不能压住“云端/MCU/外围设备”等文字。
- R03 说明：图题与表题独立编号；三线表只保留三条横线。
- 参考图中的 Java、STM32、RS485 等具体节点只是排版判例，不得复制为其他项目的技术事实。
