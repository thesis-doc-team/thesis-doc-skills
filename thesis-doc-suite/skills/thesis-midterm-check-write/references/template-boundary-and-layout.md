# 公式模板和版式边界（附件6）

以 `assets/official-midterm-template.docx` 原样复制为唯一底稿，且以 `assets/template-lock.json` 的 SHA256 锁定已审计版本。DOCX 原件含：A4 页面（约 21.00cm × 29.70cm）、上下边距约 2.54cm、左右边距约 3.175cm；1 节；1 个底层 6 行 4 列的 Word 表格；多个合并单元格；表格外的“附件6：”、标题及日期段落。学校文档自身的局部字体/行距不完全一致，**不要为了统一风格而反向修改官方固定内容**。

原表有 4 个易误判点：

1. 第 2 行题目格横向合并：只写同一合并区域一次，不对 1/2/3 列分别赋值。
2. 第 3—6 行为跨列合并大格：只有同一实际 `<w:tc>`。每格都有既有空白段落。正文只能进入这些原有空白段落，不增新段、不重画表格；填写后的 Word 成品可清理**同一正文可编辑区内未使用**的占位空段，固定栏目/签章行及学院未授权填写区禁止触动。
3. 第 5 行中“指导教师签名”和“年 月 日”是固定落款，永远不填、不移、不删。第 6 行“负责人签名（盖章）”和日期同理。
4. 教师、学院签名区与正文处于同一个合并格；不是独立单元格。程序定位时不能使用“第 N 格”猜测，也不能把正文直接写进全格的 `cell.text`（那会重置原有格式）。

## 原样保护验收

结构比较：原文件 SHA → 复制后 Word 段落顺序 → 1 节页边距/纸张属性 → 1 张表行列与 grid/merge → 每格 `tcPr` → 固定段落 `pPr` 完全一致；已填写正文 `pPr` 仅允许写入首行缩进（进度正文12pt、问题整改与教师意见正文24pt、问题整改小标签0pt），其余行距/段距/对齐一致 → 原固定文字、签名/日期 → `word/styles.xml`、`word/settings.xml` 等静态样式包均未改变。

**仅允许**填入顶部日期占位、表头空白姓名/班级、课题题目合并格、三个正文格的现有空白段落，及清理这些正文格内未使用的空白占位；学院意见在用户明确授权时才可填正文。文本超过格子的预留空间可以正常分页，但不得通过调页边距、改行距、压缩字号、隐藏固定页码等方式强行解决。

新学校模板：即使“看起来一样”，只要 SHA256 不匹配就必须由 Agent 只读分析、重建可填区域映射、更新测试，不能运行旧版硬编码位置强写，也不能偷偷替换当前安装包的原件。

## v1.2 排版回归（用用户失败稿逆向定位）

旧版 `append_content()` 只添加文本run，没有给官方**空白占位**写入正文缩进；且旧校验器不允许更改任何 `pPr`，误将“正文无缩进”视为PASS。旧文件因此出现正文顶格、部分栏目跨至第4页、第5页只剩学院签字日期。

**新的三层格式保护：**

1. 官方固定层（A）：标题、表头、栏目名称、表格宽度/边框/合并、页面、签章和页脚；与原件逐项一致，不得更改。
2. 可填写正文层（B）：允许填原有占位、设置每个正文段落 `w:ind firstLine=240/480`（进度栏约一字，问题整改和教师意见约两字），保留 `line=360` 的 1.5 倍行距，中文宋体/西文Times New Roman/12pt；独立小标签缩进0。多余的**尚未使用**的正文占位段允许清理；它们不是官方固定内容。
3. 排版结果层（C）：渲染为 PNG/PDF，每页复查；不应出现孤立签章页或空白孤页。**页数以内容自然排布为准，2~3 页均属正常**（官方空白基准 3 页仅是参考，不是压缩目标）；未经授权不得超过 3 页，确需超出先取得用户授权；不许修改A层作弊，也不许为凑/减页数增删事实、稀释或堆砌文字。

旧稿可作为**负面验证样本**，新稿需同时通过结构比对、正文首行缩进检查和最后一页正文检查。官方DOCX本体字节哈希始终不变。

## 孤页定性：空白原件对照 + 几何账（真实复盘逆向）

真实复盘（v1 出孤页返工 1 轮）：初稿三栏超默认字数带（进度 406 / 问题整改 397），行数比空白原件多约 3 行、表格被顶高——表格底边 752.3pt，可印下沿 770pt，只剩 17.7pt；而 docGrid（行距 468twip=23.4pt）下表后文末隐式段落必须占一整格，17.7pt < 23.4pt → 文末段落必被挤到第 3 页 → p3 只剩页码（硬 FAIL 孤页）。行高全 exact，删表后文末段落/缩字号行距都是改官方框架，校验器会拦。

**定性方法（与指导记录 skill 同一方法、不同定性）**：孤页/尾随空白页先用同一渲染器渲**官方空白原件**作对照组——本次原件仅 2 页、无孤页 → 属内容挤出，必须按修复链处理；若原件同样带此空白页，则属模板固有几何，判 `WARN` 披露不返工（指导记录模板那次即后者）；但空白页本身仍不得静默交付——模板固有且无法无损消除时必须如实报告用户处置（指导记录已用表尾 1pt 尾段无损消除；本 Skill 校验器禁止增段落，不得照搬该做法）。**修复链**：只删冗余措辞（重复修饰/冗词，绝不删工作项、参数、结论）→ 三栏各 ≥200 有效字与真实事实是底线 → 仍消不掉就保留事实、如实报告版式冲突请用户判断。反向同样禁止：不为凑满 3 页刻意增加字数/注水；2 页、3 页均属正常，页数按内容自然排布。
