# 官方模板原版保护与正文格式边界

**原件**：`assets/official-opening-report-template.docx`，`assets/template-lock.json` 固定来源、SHA256、版面和表格结构。本文记录真实用户官方空白 DOCX 的读取结论，并非允许重新设计版面。

## 三层样式边界

- **A 固定层（完全不可变）**：官方封面及所有栏位标签、学校信息和填表说明、表格边框/行列、正文说明、学生签名日期、指导教师审阅意见与签名日期、页面大小/页边距/页码、其余DOCX部件；不为统一范本文风更改原件。成品的 A 层与原件比对。
- **B 正文填写层**：只能占用正文第1行内部真正留白区域、合法封面值；可回收同一区域内未使用的空白占位；新增正文五号宋体、Times New Roman、1.5倍行距、首行缩进420twips，标题不缩进且段后与下文相连；文献段左对齐和悬挂420twips。正文 `[n]` 上标是 Word run 的 `vertAlign=superscript`。
- **C 呈现层**：Word 渲染后的逐页图片有无错字、空白孤页、参考文献多重编号、URL两端对齐拉伸、正文无首行缩进、长章题悬空、签字栏孤页。不得为满足某个固定页数而修改 A 层或夸大/删改真实内容。

官方说明要求开题报告七项内容、正文不少于3000字、文献不少于10篇、教师审阅意见不少于50字；但教师意见应由教师本人完成，生成器只能保留官方原有区域，不代写签名。

## 自动检查分工

`build_report.py` 检查官方模板哈希并填授权空白，`check_report.py` 检查原件静态部件、正文格式、首行缩进、所有文献编号与行距；`render_visual.py` 将所有页面截图并仅做孤页预检；**Agent必须真的逐张打开图像**。原版 DOCX 可能存在 Word/WPS渲染差异，未运行 WPS 不得声称 WPS 验收。

## 新版学校模板

即使文件名相似，哈希与锁文件不符必须停止，以只读方式重新审计固定栏目和可写区域，完成测试并由用户授权适配，**不能用旧脚本硬编码坐标强写**。
