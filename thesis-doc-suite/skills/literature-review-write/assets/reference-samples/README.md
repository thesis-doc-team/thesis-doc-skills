# 四份起始文献综述范本｜去标识化使用规范

本目录来自用户最早提供的四份完整文献综述范本。保留与写作有关的段落顺序、语体、参考文献区块及可读的原排版；已替换封面中的学生姓名、学号、学院、专业、班级、指导教师、职称等个人身份字段，并清理常见 Word 核心个人元数据。`samples-manifest.json` 记录脱敏文件校验值。

| 样本 | 可学习内容 | 禁止迁移 |
|---|---|---|
| A（环境监测） | 引言→现状→评述、参考文献列表、教师审阅措辞 | 原课题的危险参数、统计数据、错误引用字段 |
| B（数据平台） | 按技术分项拓展现状或评述、研究背景写法 | 旧的技术选型、缺失的三级编号、错误空行 |
| C（智能设施） | 国内外现状区分、末尾简明评述 | 原项目设备清单、与课题不相关的引用 |
| D（农业巡检） | 研究意义、场景技术关联、论证顺序 | 项目功能、未经核验的数据、重复段落 |

范本中的科研论文作者及书目标题属于示例正文的学术信息，不代表可直接复用为本项目引用。**所有新的文献都需要在当前项目 `project-assets/references.json` 独立核验后才能使用。** 范本有历史遗留的排版与引用缺陷，不是可直接提交的完成品，也不能作为官方排版母版。

最终排版以 `../official-literature-review-template.docx` 为物理真源，原则是“只分析范本、只填官方模板”。
