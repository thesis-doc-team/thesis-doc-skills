# 四份匿名任务书范本（只读，不参与当前项目资产）

| 编号 | 范本 | 优先学习 | 注意避免 |
|---|---|---|---|
| SAMPLE-A | 农业巡检 | 连续叙述的技术内容、八阶段进度、规范教师意见 | 不能照搬具体器件、实际项目内容或旧日期 |
| SAMPLE-B | 数据可视化 | 总述+编号分任务、开发阶段拆分 | 原范本教师意见为空；原稿存在参考文献不完全相关，不可作核验样板 |
| SAMPLE-C | 设施监测 | 技术模块叙述、文献/开题/开发/测试分段 | 原稿文献重复，不能复用未核实条目 |
| SAMPLE-D | 环境安全 | 总述+编号功能、软硬件进度 | 正文缩进存在差异，不能推翻官方模板 |

- 四份范本均来自用户最初提供的任务书，已替换人名、学号、具体班级、历史日期、原课题标题、参考文献元数据，并概括化原项目专有技术细节。保留了主要正文的技术叙事用于逆向学习，不代表当前项目技术事实。
- **文献行全部改成明确无效的展示条目**，绝对不能写入当前项目 `project-assets/references.json`；实际引用必须查证真实论文。
- 元数据中的编辑者、历史时间与 WPS 文档跟踪标识已清理；`samples-manifest.json` 记录每份脱敏件 SHA-256。
- 四份已填范本格式不完全一致，官方空白 DOCX 始终是唯一物理版式权威。详见 `references/anonymized-sample-text.md` 和 `references/sample-style-audit.json`。
- 如需替换范本：先脱敏、扫描全部 DOCX 包内 XML/关系/属性、逐页渲染、审计，再更改 manifest。不得直接将未经脱敏的原始范本塞入安装包。

- 匿名范本不携带内嵌字体二进制；其中学术文献编号若由 Word 自动编号产生，不再叠加文本编号。
