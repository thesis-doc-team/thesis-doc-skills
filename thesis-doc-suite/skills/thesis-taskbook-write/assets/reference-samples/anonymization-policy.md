# 匿名化技术边界（本工具包实例）

- 处理源：用户最初提供的四份已填任务书，**原始文件不随 Skill 分发**。
- 人名、学号、班级/届别、导师、签署相关旧日期、原课题正式标题替换为泛化示例标识；不保留唯一身份识别字段。
- 参考文献元数据不是“已核实参考文献库”，全部替换为无效排版示意文本，禁止转入任何项目资产。
- Word 文档属性（author、last_modified_by 等）使用匿名标识，清理 `docProps/custom.xml` 和 `customXml/` 及相关关系，避免 WPS 隐藏的用户跟踪记录泄漏。
- 对 ZIP 内所有 XML/关系文件实施禁用标识扫描；以 `samples-manifest.json` 记录摘要，修改须同时更新 SHA-256 和审计。
- 去标识化不保证逐字还原源文排版，可能造成自然换行变化；**只用它们学习语气与布局差异，不允许替代官方空白模板**。
- 这些文件始终存于 Skill 安装目录 `assets/reference-samples/`，不写入某个真实项目的 `project-assets/`。

- 匿名范本额外去掉原 DOCX 内嵌字体二进制文件（保留字体**名称/样式定义**），避免把用户提供的嵌入字体作为附件分发。
- 对原文件使用自动列表编号的文献段，仅保留列表机制，不额外插入手动 `[n]`，避免 `[1][1]`。

- 第二轮匿名化把领域独有的硬件型号、厂商平台、具体应用功能组合概括为“通用控制器/数据平台/环境参数”等，不影响段落和编号结构；因题目替换造成的语义不通顺也已修正。

- 脱敏范本的 `docProps/app.xml` 中 WPS 客户端特定标识及文档历史编辑时间已清零或改为统一匿名值，并清理 Word 修订会话 RSID；官方空白模板原件未进行此处理。
