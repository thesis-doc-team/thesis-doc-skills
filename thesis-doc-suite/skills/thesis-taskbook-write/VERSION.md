# thesis-taskbook-write — 1.2.0

## 本版基线

严格以本轮用户上传的 `thesis-taskbook-write-v1.1 (2).zip` 为基础升级。未覆盖用户自定义项目资产，未改动官方 DOCX 原件；引用 `thesis-midterm-check-write-v1.3` 的**匿名参考样本、风格统计、模板哈希锁、视觉预检查**方法，不合并其“问题与整改”等中期检查专属文书逻辑。

## V1.2 新增与修正

1. **四个脱敏任务书范本（DOCX）** + 样本元信息及 SHA-256，原始个人信息/原参考文献元数据不随包传播。
2. **匿名样本文字镜像与格式统计**：12段设计内容、24段周进度、3段有文本的教师意见用于观察真实格式分歧；具体统计以 JSON 为准。
3. **官方模板锁**：`assets/template-lock.json` 与 `scripts/template_lock.py`，避免 9×4 结构相似但版本不同的文档被错误填充。
4. **禁止覆盖既有版本**：`fill_taskbook.py` 对已存在目标直接拒绝，需改用新 `-vN`。
5. **渲染预检查**：`scripts/render_visual.py` 输出全页 PNG 与预检查报告；所有结论默认 PENDING，必须实际逐张查看；不宣称 WPS 实测。
6. **自然分页纠偏**：页数不设固定上限；只修正真实溢出、异常空白、格式错位；明确撤销 V1.1 中“超出基准页数失败”的不合理规则。
7. **保留旧共享资产契约**：`project-assets/`、`deliverables/`、`.skill-tmp/`、引用稳定 ID、计划共享、活动记录、清理机制完全保留。
8. **回归测试**：新增匿名化扫描、风格审计复现、模板锁拒绝与历史文书禁止覆盖。
9. **匿名范本健壮性**：清除自动编号与文本编号叠加的 `[1][1]` 问题；移除匿名样本中的嵌入字体二进制，但保留 Word 字体名称和段落样式。

## 边界与后续

- 仅写任务书；不生成开题报告/中期检查报告/学位论文/HTML。
- 测试中的文献及示例条目均不真实，不代表完成用户具体项目的真实检索；正式生成仍必须核验论文来源与文献元数据。
- 自动视觉预检查不是人工复核，更不是 WPS 客户端核验。

10. **模板固有分页甄别**：实测官方模板末条附注可能单独分页，必须区分模板原有布局与新填文字带来的异常，不因孤页强行改版。

11. **跨中期检查共享进度扩展**：任务书资产客户端支持可选 `progress.json`（PROG-ID，来源、核验状态）；保持任务书 `schedule.json` 的计划属性，绝不将进度事实移作任务书拟定计划。
12. **匿名范本措辞深化**：不仅替换姓名/学号/标题/历史日期/文献，而且把原始项目具体厂家、模块型号、独特功能组合概括化，保留叙述结构和编号节奏；调整因替换标题导致的不通顺句式。

13. **隐私/元数据复检**：四份 DOCX 去除文档作者姓名、学号及相关旧年份，统一匿名创建/修改时间、应用程序信息与会话修订标识；测试脚本本身不保存被删除的个人姓名和学号。
