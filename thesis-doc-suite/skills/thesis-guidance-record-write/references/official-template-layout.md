# 官方模板结构审计与不可变约束

## 审计结果

来自本轮用户上传的`05_塔里木大学毕业论文（设计）指导记录(1).docx`。

- 官方锁定文件：`assets/official-guidance-template.docx`，哈希见`assets/template-lock.json`。
- 2节（封面与记录部分的页面属性有差异），A4；2张表：填写说明表4×2，指导记录表26×11逻辑列；每13行一条记录。
- 记录区：第0行姓名/学号/专业年级，第1行题目，第2行时间/地点，第3行指导方式，第4行指导内容标题，第5行内容正文，第6—11行评价，第12行双方签字及日期。下一条从第13行重复。
- 逻辑列存在合并格：不能仅以 `row.cells[j]`的每列文本为不同的物理格；结构校验须比较`tcPr`、`trPr`、`tblPr`和`tblGrid`。
- 官方正文区域原文“分条列出。如：……/指导教师……/……”是填写示例，允许在**内容区**替换；其它栏目字样不得改。

## 原表固定高度与分页

正式空白表一组行高主要为（pt）：34、34、28.4、28.4、28.4、265.6、34×6、70.4，合计约727pt，且第2节上下页边距均约72pt，A4可用高约698pt。表格自然溢至下一页；**不能为追求每次整页而偷偷修改行高/页边距**。

可以：在现有表格中按13行深复制，增加次数；在允许填写的位置写正文并统一正文段落缩进；保留所有固定校级栏目与评价；页数随内容自然生成。

不可以：抹掉“指导记录填写说明”；改“每月不得少于4次”等文字；添加独立“参考文献”“指导总结”栏目；把教师签字改成机器签名；用自绘11列表格代替原始合并单元格；为了页数把字体缩小到不可阅读。

源文档仍需保留原始字节；输出文档任何固定 `trPr/tcPr/tblPr/tblGrid` 变化都应被结构校验拦截。

## 尾随空白页（模板固有几何，非孤页缺陷）

真实复盘实测：官方空白原件用同一渲染器渲染出 **5 页、第 5 页整页空白**；8 次记录成品 11 页、第 11 页整页空白，同源。复盘几何账：13 行记录块恰满页 + 表末文末标记约 312twip 溢出，恰好压出尾随空白页；行高全 exact，措辞增删改变不了分页。

处理定式：成品末页空白先用同一渲染器渲染**空白原件对照组**再定性——原件同样空白即判 `WARN—模板固有几何` 如实披露（附几何账），不返工、不为消空白页增删事实或改框架/缩字号；对照组没有该空白页才按内容排布/孤页路径排查。与"固定行高跨页"是两回事：跨页是单条记录被表格切开，尾随空白页是末页整页无内容，两者都属模板固有几何。
