# 去标识化指导记录写作范本

`anonymized-guidance-sample.docx`来自用户最初提供的一份已填写指导记录范本，经过人物、学号、课题名称、班级届别、日期、地点、作者元数据等去标识化处理，保留原有记录顺序、段落/表格与问题-修改意见写法。

**只允许用于**观察语言节奏、一个技术问题对应一条整改意见、每次记录主题递进等写作共性。**不允许**从本样本继承个人信息、教师评价、真正发生过的日期、技术功能或“已完成”事实，也不以其不规范的复选框、字号或断页修改官方新模板。

正式排版始终以`../official-guidance-template.docx`为唯一底稿。原始含身份信息的范本不随此Skill打包分发。
