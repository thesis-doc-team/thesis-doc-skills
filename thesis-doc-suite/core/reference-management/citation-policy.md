# 参考文献真实性与引用规范（跨 Skill 规范版）

> 本文件是全部文书 Skill 共用的文献检索、核验与引用规则的规范来源。各 Skill 自带的 `references/citation-policy.md` 是其视角的兼容说明；冲突时以本文件的数据规则为准，体裁差异（如文献数量门槛）以各 Skill 的 SKILL.md/学校要求为准。

## 1. 真实性硬门槛（不可绕过）

1. **禁止伪造**：不得凭语言模型记忆拼接作者、论文名、卷期、页码、DOI；不得虚构文献、项目成果、研究数据。参考文献内容不得伪造，宁缺毋滥。
2. **优先可核验来源**：中国知网（CNKI）、万方、维普、学位论文库、期刊/出版商/学协会官网、IEEE、ACM、ScienceDirect、Springer、Crossref/DOI、官方标准/RFC/厂商手册。
3. **CSDN 等技术社区**只作技术背景/排障补充，必须标注为网页/技术资料（`source_type=web` 等），**不得冒充期刊论文**，不宜以大量博客替代正式论文（各 Skill 默认上限见其 SKILL.md，如开题报告默认 ≤2 项）。
4. **查不到就是查不到**：无法访问来源核实时 `verified=false`，执行汇报列为未完成门禁；只看到检索页/目录页只支持"论文存在"，不能推断实验结论。

## 2. 项目文献库（REF-xxx）字段要求

每条至少：稳定 `id`（REF-xxx）、`citation`（著录文本，不含 `[n]`）、`source_url`、`source_type`、`verified`、`checked_at`（verified=true 时必须）；建议：`doi`、`tags`、`project_relevance`、`limitations`、`notes`。同 DOI/同题跨平台去重。

- **先复用后增补**：先读 `project-assets/references.json` 筛选 `verified=true`、主题相关条目；缺才检索新文献，**先核验、再 `merge --kind references` 入库、最后在本文书中引用**。
- 更新已有条目须有证据与理由：`--replace --reason`，写入 `activity.jsonl`；不得静默覆盖。
- 文献仅存在本项目库；不写入插件内置目录；不从旧范本继承参考文献。

## 3. 文内编号与引用标记

- 稳定 ID（`REF-xxx`）与文内编号（`[1]`…）**分离**：文内编号按**本次文书正文首次引用顺序**生成；同一 REF 在不同文书可有不同编号。
- 引用标记约定（各 Skill 生成器负责转换）：开题报告用 `[[cite:1]]`/`[[cite:1-3]]`，文献综述用 `[[REF:REF-001]]`；正文引文必须是真正的 Word 上标（`w:vertAlign=superscript` / `run.font.superscript=True`），不是 Unicode 上标字符。
- 文后参考文献列表正常基线排版，编号连续、一一对应、无重复；著录格式优先学校要求（通行 GB/T 7714），长 URL 不得被两端对齐拉伸。

## 4. 核验记录

每条文献保留检索地址（`source_url`）与实际核验时间（`checked_at`）；核验状态随 `verified` 显式记录。各 Skill 交付时提供文献核验台账（或在执行汇报中列出）：复用/新增条目、REF-ID、核验状态与缺项。`record-use` 登记本文书实际引用的 REF-ID。

## 5. 数量门槛（服从学校/用户要求，不为凑数造假）

| 文书 | 默认门槛 |
|---|---|
| 任务书 | ≥10 篇正式真实文献（官方模板"不少于10篇"） |
| 开题报告 | ≥10 篇，正文与文末一一对应 |
| 文献综述 | 默认 ≥8 篇独立真实文献（样本 11～15 篇） |
| 中期检查 / 指导记录 | 无参考文献栏，不主动插入；文献仅作背景证据登记 |
| 技术文档 | 不设文献门槛；外部资料须标注来源与"背景信息"性质 |
