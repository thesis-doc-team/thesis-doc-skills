# 指导记录体裁逆向方法｜来自初始两份已填范本与正式空白表

## 1. 源材料与权重

- 官方空白模板：确定**标题字段、填写说明、13行每次记录、评价、签字、A4 页面与字号框架**；权重最高。
- 已填样本A（原来的“多功能设施监测设备”范本）：关注写作顺序、问题/建议的完整对应、从硬件到论文的推进；不能复制人物、日期、评价。
- 已填样本B（原来的“数据传输与可视化系统”范本）：关注通信排障、前端、系统联调与论文阶段之间的阶段递进；部分条目不完整和正文被挤压，是负面样式示例。
- 已完成胡杨林安全监测系统指导记录排版稿：用于检验“按项目技术主线连续8次”思路；**其已写内容仍是拟稿，不能当真实会谈证据**。

## 2. 求同：共同“文体指纹”

1. 每次记录在同一个官方布局中出现身份、课题、时间、地点、方式、指导内容、三类评价、教师/学生签字。
2. 指导内容分为**指出存在问题**和**提出修改意见**两组，并分条编号；不是摘要、技术说明书或论文正文。
3. 每条问题通常指向一个具体模块或文稿缺陷；每条建议说明整改动作。整体从系统方案、单元测试、应用交互、通信到论文审阅递进。
4. 语句短、可操作、适合打印和导师批阅；避免套话和过度学术化。一般每次2个问题与2个建议；过长易挤压。
5. 不把教师实际勾选/签字视为AI可替代文字。

## 3. 存异：冲突裁决

| 异同 | 统一规则 |
|---|---|
| 已填样本某些段落未逐条对应 | 强制问题与建议用同样编号对应，缺失项需补齐后才可生成 |
| 部分样本字号、字体/缩进不统一 | 官方案例中固定字样不改；仅在**可填写正文**采用统一宋体/西文Times New Roman、10.5pt左右、首行约21pt |
| 某些参考范本的复选框出现“£”或“R” | 绝不照搬乱码/已勾选状态；原官方的“□”保持空白 |
| 日期/实验室/学生/教师有差异 | 一概视为其他人事实，不继承；当前项目无证据则留空 |
| 官方模板只有2次完整空表 | **每13行复制一组**，可扩展为不少于8次，不按空白页数限制最终页数 |
| 原官方表可能自然跨页 | 不私改行高、边距解决；逐页预检并报告跨页，取得授权前不得优化固定骨架 |
| 技术文档写了“已实现”但无实验日志 | 改用“资料列明/建议核验/尚需测试”等审慎动词 |

## 4. 写作推理流程（可复用，不锁定任何特定系统）

输入技术资料 → 拆成功能与模块 → 识别实施状态/证据 → 按合理技术依赖排序 → 每阶段找**真实缺口或待验证风险** → 写问题（对象+不确定/缺陷）→ 写对应修改意见（动作+证据/验收）→ 按公式排版 → 与周计划和真实指导证据校核 → 不对无法证明的日期/实施结果做断言。

**优先“内容正确、来源可追溯”，其次“形似范本”，但官方模板架构不可牺牲。**
