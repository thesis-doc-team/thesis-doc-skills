# A4 图表排版规范（technical-visual-assets v1.4.0）

## 1. 版心计算

> **职责边界**：A4 门禁只检查“图表能否放进目标文章的正文区域”，**不要求绑定章节，也不负责把图插入 Word**。章节归属、图号重排由写作 Skill 或用户处理。

1. 纸张：A4 = 210 × 297 mm（横向 297 × 210 mm）。
2. 可用正文宽 = 纸张宽 − 左页边距 − 右页边距。
3. 可用正文高 = 纸张高 − 上页边距 − 下页边距。
4. 示例：左右各 25 mm → 正文宽 **160 mm**；不是 210 mm，也不是固定 190 mm。
5. 多节文档必须定位图片/表格所在节，分别计算；不得用第一节代替所有节。

命令：

```powershell
python scripts/a4_layout.py profile --template "E:\official\官方模板.docx"
```

输出 `content_width_mm`、`content_height_mm`、`figure_max_width_mm`、`figure_max_height_mm`、`caption_reserved_height_mm`。

## 2. 图片尺寸与字号

- 图片宽 ≤ `figure_max_width_mm`（通常为正文宽 − 2mm 安全余量）。
- 图片高 ≤ `figure_max_height_mm`（正文高 − 图题预留 − 上下文间距；纵向再取正文高 82% 的保守值）。
- 插入 Word 后图中文字 ≥ 9pt，建议 9–10.5pt。
- 如果缩放后文字 < 9pt：重新排布/拆图/加宽节点，**不得**强行缩小。
- 不允许拉伸变形；保持原始宽高比。
- 优先嵌入型（inline），不要环绕浮动覆盖正文。
- 不得与页眉/页脚重叠。

命令：

```powershell
python scripts/a4_layout.py fit-figure --template "E:\official\官方模板.docx" --width-mm 155 --height-mm 95 --text-pt 9.5
```

## 3. 图题

- 图题在图片下方、居中。
- 中文题 + 英文 `Fig. X-Y` 题；图号按目标文书要求（章节号或项目内序号均可），本 Skill 只存元数据。
- 图题不画进 SVG/PNG 像素，用 Word 原生段落。
- 图与图题同页；不得图题孤页、图题被页脚遮挡。
- 图题字号/字体/段前段后优先服从官方模板；模板未规定时中文宋体、英文 Times New Roman，10.5pt 左右。
- 图题与正文之间保持模板规定间距，不用空行硬撑。

## 4. 图片格式

- 优先 SVG（矢量、可编辑、清晰）。
- WPS/旧版 Word 不支持 SVG 时，用 300 dpi PNG 位图；PNG 只作兼容副本，SVG 仍为源。
- 不把表格转成图片；不把长图裁成多张无法对应的碎片。
- 图片文件缺失或尺寸与元数据不一致时 BLOCK。

## 5. 表格

- Word 原生可编辑表格，不用截图。
- 新生成学术数据表严格三线表：表顶、表头下、表底三条横线；无竖线、无数据行间横线。
- 表格宽 ≤ 正文宽；过宽按语义拆成关联子表并重复关键列，不删数据。
- 文字 ≥ 9pt；表头跨页重复；表题按模板位置。
- **所有表头和数据单元格必须水平居中 + 垂直居中**；`three_line_table.py apply` 自动设置，`audit` 未居中即 BLOCK。
- 官方固定表单不改；冲突时 BLOCK 并请用户确认。

## 6. 插入后验收

1. `a4_layout.py audit --docx`：图片/表格 XML 尺寸、浮动/嵌入、超版心。
2. `figure_qc.py --docx`：图片下方中英文图题、居中、图号一致。
3. `three_line_table.py audit --indices ...`：新增数据表三线表 PASS。
4. **Word/WPS 逐页实际渲染**：检查出界、文字重叠、表格横向溢出、图题孤页、图表跨页截断、字体/乱码。
5. 没有实际页面截图/目检，不得宣称“Word 版面验收通过”。

## 7. 常见失败

| 失败 | 原因 | 修正 |
|---|---|---|
| 图宽 190mm 塞进 160mm 版心 | 用固定宽度而非模板版心 | 重新测量、缩图或拆图 |
| 图中文字 6pt | 靠缩小图适配 A4 | 重排/拆图，保持 ≥9pt |
| 图题孤页 | 图高 + 图题超过剩余高度 | 调整图高/分页，图题与图同页 |
| 表格横向溢出 | 列宽总和 > 正文宽 | 按语义拆表、重复关键列 |
| 三线表出现竖线 | 用了网格样式 | 用 `three_line_table.py apply` 并 audit |
| 图片被拉伸 | 手动改宽高比 | 保持原比例，按宽度等比缩放 |
| 中文乱码/方框 | 字体缺失 | 用模板兼容字体（宋体/Times New Roman），渲染检查 |
