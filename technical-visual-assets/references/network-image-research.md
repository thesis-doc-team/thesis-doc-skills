# 模块级联网找图 SOP（仅图片，禁止自动装依赖）

**强制视觉样本**：选模块实物图前阅读 `image-selection-examples.md` 并实际查看五张原图。前三张是裸芯片/孤立配件/芯片内部框图反例，后两张是完整步进电机/完整传感器小板正例；不可只凭关键词判断。

1. 查询依据：`project-technical-doc` 正式 MD + `FACT-xxx` 中真实模块、精确型号与状态。未知板卡版次不能猜。
2. 默认使用现有 WebSearch/WebFetch/浏览器（若 Claude Code 当前提供）；有现成 DDGS 时可调用本目录 `scripts/search_candidates.py`；无 DDGS 用 Python 标准库 Commons API。不要为了找图去 pip/npm/npx/apt/brew 安装任何东西，也不拉取爬虫、浏览器驱动、模型权重。
3. 在百度/CSDN 上找到的图片，至少点开来源文章并追溯图片原页；搜索缩略图和 CDN 文件名不构成型号或版权核验。找不到原页只记线索，不能批准。
4. 网站图片的视觉审核要回答：①主体是否为完整模块/整板；②型号标签/官方说明与 MD 是否匹配；③能否清楚展示该模块的实际结构或外观；④图片是否清楚、没有裁掉关键主体；⑤来源和复用授权是否明确。缺一项不可批准。
5. 明确拒绝：电阻、电容、引脚局部图、任意 PCB 小角、芯片资料截图冒充整板、无关连接线/配件、系列相似但型号不同图、模糊/严重水印/只有缩略图、装饰科技背景、AI 伪造实物照。
6. 查无完整模块图则留 `MISSING`。不为了四类完整性伪造或制造无意义配图。
7. 查询结果只打印 URL 等候选；保存具体图片必须当前任务明确授权，带 `--allow-image-download`，严格限制受控运行区与 PNG/JPEG/WEBP 内容，下载前后保留核验记录。未知许可不能标为可公开传播。
8. 官方图同样可能需要许可；记录作者/权利人、许可文本/链接、访问日期和使用范围。图片实际用途由下游业务 Skill 检查。

9. 对模块照片必须区分完整执行器、完整 PCB 模组、完整控制板和其内部的小元件；主体完整性与准确型号必须分别核验。即便是“正例”外观，不符合项目型号也不得批准；白/透明背景不应当被当成无关图片。
10. `review --approve` 审核网络实物图必须明确 `--subject-level complete-device|complete-module|complete-board`，写明主体包含哪些主要部分；不能用裸芯片、局部电阻或芯片内部示意图去填完整模块图的缺口。
