# 项目参考文献与技术来源政策（不等于 Word 文献栏目）

**本学校中期检查表无参考文献栏目。** 文献是项目级共享研究资产，用于支撑技术背景、设计合理性与排障建议，**默认不将列表塞进中期检查表**；也没有“10篇论文”的独立门槛（该要求属于任务书的官方模板，与本 Skill 边界不同）。

## 来源优先级

1. 论文/学位资料：中国知网（CNKI）、万方、维普、高校学位论文库、出版商及学协会官网；跨学科可用 IEEE/ACM/Springer/ScienceDirect、Crossref/DOI。
2. 设备/协议：ST、Arm、Sensirion、SIMCom、MQTT 标准组织或其它对应厂商/标准官方材料，以具体版本日期为准。
3. 开发实践：CSDN、开发者论坛、个人博客可辅助解释调试流程，但必须标记为 `blog`/`web`，不得伪装为期刊文章或替代关键技术/测试证据。

每条新条目登记 `REF-xxx`、原始 `citation`、`source_url`、`source_type`、`verified`、`checked_at`、`tags`、`project_relevance`、`notes`。先查原文或真实数据库记录页面再写作者/论文名/年份/DOI；不可根据猜测将 verified 设为 true。检测标题、DOI、引用格式去重。对于本表无实际用到的文献，不应为了统计数量虚填已使用。

## 资产更新与跨 Skill 复用

先读 `project-assets/references.json`，相关且已核验条目用稳定 `REF-ID` 关联；要修正引文用显式变更+证据理由，不让后续 Skill 偷偷覆盖。任务书或开题报告将这些条目转换为各自正文 `[1]...[N]` 编号，本 Skill 不改变共享 REF-ID，也不对旧文书自动重排编号。输出执行汇报记下实际使用数量、来源类型、核验限制；检索不可达则保持未核验，绝不造假。
