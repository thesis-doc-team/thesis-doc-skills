# 四份已完成范本的逆向写作规则（去项目化，不迁移私人信息）

## 1. 研究结论

按用户最初提供的四份同专业文献综述做多数特征归纳，不以单份范本压过官方模板。

| 比较维度 | 高共性做法 | 差异与判定 |
|---|---|---|
| 题目与个人信息封面 | 学校、文书名称、题目、学生姓名、学号、学院、专业、班级、导师、职称 | 具体姓名/学号等是私人数据；只有真实本项目明确提供才填 |
| 引言/背景 | 从场景问题、研究必要性、应用价值引入 | 标题可叫“引言”或“研究背景”；默认“1 引言” |
| 研究现状 | 按国内/国外或不同技术方向叙述 | 避免泛泛说“国外先进”；必须落实到实际论文证据 |
| 评述 | 汇总方法优势、限制、与当前方案关系 | 有的范本“3 设计内容”代替“3 评述”；优先多数用法与文献综述本义 |
| 参考文献 | 编号列表、主要为期刊和学位论文 | 篇数旧样本约11～15，官方本次无固定篇数；不搬论文、不虚构 |
| 文中引用 | `[1]` 等编号标记 | 必须按用户本轮要求实现真正 Word 上标（范本是否正确不影响硬约束） |
| 教师意见 | “该生”评价文献能力、研究理解、课题结合、下一步工作 | 必须拟稿≥50字，但不得伪称教师已审核 |
| 字数与行距 | 以官方正文≥2500字、宋体五号、1.5倍行距为准 | 忽略范本中异常的大段空行、错位或额外分页 |

## 2. 文章组织方法（可复用的“思维”，不是可复用的“结论”）

- **引言**（约 15%～25%，视项目而变）：核心环境/行业问题 → 传统方法局限 → 本课题为什么需要研究；论据标注引用。
- **国内外研究现状**（约 45%～60%）：主题分类比较，至少讨论技术路径、适用场景、成果与限制；在有论文支持的地方适当区分国内外，而不是凭空分高下。
- **评述**（约 15%～30%）：从比较过的证据概括研究空白、限制条件和本课题合理切入点；“研究尚缺乏”须有检索范围与证据支持，不能绝对化。
- **参考文献**：本文章实际引用的真实资料，按首现顺序输出。

比例仅是写作指导，**不是固定字数配额**，仍以项目学术实质为先。

## 3. 教师意见范本风格反向规则

四份例文中常见的逻辑顺序：

```
该生（主体）
  → 查阅/整理/理解课题相关文献（能力）
  → 能把握国内外研究现状、研究意义（综述水平）
  → 能结合当前选题分析现有问题并形成设计思路（针对性）
  → 综合评价及后续工作意见（以教师最终审定为准）
```

建议一个自然段 120～220 汉字；简洁正式，以客观可核对的评价为主，不出现“世界第一、完全解决”等夸大语。范本里常有“同意进行毕业设计下一步工作”，如用它只能作为**待教师确认的拟稿文本**；不能填写教师签名或签署日。

## 4. 本次格式事故的防回归设计

1. **不能 new Document() 重建官方格式**。早期生成稿增加了封面新表格，虽局部看相近，实际上改了官方 Word 结构。
2. **不能使用普通空格/行末下划线制造标题**。一旦遇到字体或 Word 渲染差异，题目第二行偏斜、底线消失、文字压线；必须在原段落做可控填充，逐张截图核验。
3. **题目文字及下划线分离管理**。题目两行各自中心对齐，线条统一左右边界；不得以句子长度变化自动改变线长。用户标题更长时，先分行并做渲染后调整，而不是缩小学校封面标题字号。
4. **正文上标必须是真实字体属性**。不能只用“看起来上标”的 Unicode 或普通 `[N]`。
5. **引用必须核验**。初期样本中存在损坏的 Word 引用字段显示 `Error: Reference source not found`、不相关论文、重复记录；这些不是可复用的排版知识。
6. **末页导师区不能代签**。可以生成一段待审定评价，签字和日期位置应是模板原物。
7. **截图不是“形式动作”**。使用者已经多次发现标题/线条不一致，必须裁剪放大封面局部，检查实际呈现，直到修复。

## 5. 匿名样本使用边界

`examples/anonymized-style-reference.docx` 基于最初样本替换了学生姓名、学号、导师与单位/班级填充值，并清理文档主要个人元数据。原文公开参考文献作者仍作为书目著录，未把公开论文作者当作学生私密资料。样本可能仍含旧版技术观点、写法不严谨和引用残缺，**仅用于读结构/句式/篇幅，不允许整段照搬成品**。
