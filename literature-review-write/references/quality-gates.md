# 文献综述质量门禁与截图验证报告

## G1 官方模板不可变部分

必须**原模板副本**填写；分节数、页面尺寸/页边距、表格总数与 grid、表格行列/边框属性、固定提示文字、教师意见区标签、签字日期字样及位置不得重建。允许清理“供正文填充的空白段落”和在原单元格内添加内容段落；不允许新封面表格、修改页眉页脚和页码。

## G2 写作内容

- 正文实际字数不少于2500；有引言、相关研究现状、综合评述、参考文献；引用主题相关。
- 研究现状是多篇论文的对比综合，而不是无证据的概括；结论与研究事实一致。
- 不混入其他范本的姓名/学号/导师、技术设备、项目成绩、旧课题名称。
- 项目资料状态正确：“已完成”“计划实现”“预计测试”不能互相偷换。

## G3 参考文献

- 来源真实可核验、元数据完整，与题目相关。优先学术库；CSDN 等技术网页只作为正确类型补充。
- 项目 `REF-ID` 与正文 `[N]` 独立，正文按首现排序，参考文献编号连续、无重复、文内每条有出处。
- 正文 citation run 必须 `superscript=True`，书目清单编号必须 baseline。无无效交叉引用和代码标记。

## G4 教师审阅意见拟稿

至少50字（口径以最严者为准：校验端只算汉字/字母/数字；50~60 字区间最易翻车，写足余量），“该生”口吻→文献能力→研究与选题结合→综合评述；**教师意见拟稿统一规范（跨文书共用写法）五要素链**：①主体与选题→②能力→③文书质量→④针对性→⑤收束`建议按计划进入毕业设计下一阶段工作。`（**不加"…审定为准"等元话语尾巴**）；不得宣称教师已经审核通过；不动签名与真实日期，不写“优秀/良好”等等级。

## G5 **截图视觉复核**（此门禁不可省略）

1. **实际渲染**：DOCX 转每页 PNG；记 `engine / page_count / inspected_count`。
2. **逐张实际查看**：每页 PASS/WARN/FAIL（不能仅靠 Python 文本审计或拼接缩略图）。
3. **必看封面局部放大**：两行题目中心、文字与线不重叠、线左右端一致；学生姓名/学号/其他字段线长一致；字体无缺失、未被遮挡；引导段与文字下划线交界处的小空档为 Word 制表位引导段固有特征，两行一致即非缺陷，不得为消除它改动官方机制。
4. **必看第二页与中间页**：说明段落保留、标题层级、行距、1.5 倍行距、正文上标、跨页表格边框、空白页及孤行。
5. **必看末页**：参考文献行间距、正常编号、教师意见进入原区域、签字与日期存在、无额外奇怪表格/分页。
6. **实质性分页门禁**：官方模板页数仅是参考，成品按内容自然排布（≥2500 有效字是底线）；未为凑/压页数增删事实或改版式；孤页已消除，或如实报告待用户判断。
7. 修正后**重新全部渲染检查**，不只局部复看；存在 FAIL 时不得宣称最终通过。
8. WPS 客户端是否实测必须如实披露。渲染工具并不等同于 WPS。

## 结果报告模板

```text
课题：...
版本：vN
模板：...（SHA256）
技术资料：...；本轮素材真实性：...
正文：...字；文献：...篇（复用.../新增.../待核验...）
引用：正文上标...处，编号连续...，书目基线检查...
审阅意见：...字（拟稿，待教师确认）；签字日期空白
结构审计：PASS/WARN/FAIL（差异...）
视觉截图：使用...，渲染...页，实际逐张检查...页
各页结果：p1 PASS / p2 PASS ...
封面局部截图：已实际查看/未查看；发现问题...
WPS 实测：是 / 否（只有真打开 WPS 才写是）
共享资产：新/旧 REF-ID、facts 变更、使用记录 sha256...
执行结果：成功 / 部分完成 / 阻断；待办和原因...
中间文件清理：已清理本轮 <run-id> / 未清理及原因...
```

特别注意：有些渲染器会忽略表格单元格内 `keep_with_next`，若一级标题孤立在页末，可在该章节草稿尝试 `page_break_before: true`，但部分渲染器可能仍忽略跨页表格中的强制分页。若无效，必须修正该章节附近新增内容的分段并重渲染；未消除时不得声称视觉通过。

## v3.2 稳定性补充（参考中期检查 Skill）

- **G0 模板锁**：`assets/template-lock.json` 的 SHA256 必须与本次指定官方母版完全一致；不同模板先重新测绘、测试，不可直接复用 `fill_review.py` 的段落索引。填充不能覆盖已有 `.docx` 版本。
- **G2 句子分层**：技术文档中的已实现、设计目标、未验证功能不可混同。三大正文主章 1/2/3 连续，二级节标题可通过 `kind=subheading` 书写；正文不靠复制范本机械凑2500字。
- **G3 多文献引用**：除单个 `[n]` 外，对分组引用 `[1,2]` 与范围 `[1-3]` 逐号核验是否与文后条目集合一致、编号是否按首现顺序排列。后文同号可以重复，但列表不得无引文条目。
- **G5 视觉证据**：先用 `render_visual.py` 保存实际每页截图，再逐页看图；需要特别检查封面两行文字是否与下划线重合、线条是否等长，正文表格跨页是否标题孤立，末页是否单独遗落签字。自动预警零条 **≠** 视觉验收通过。
- **G6 故障测试**：每次改脚本必跑 `tests/smoke_test.py` 和 `tests/test_regression.py`；程序 PASS 后再实际渲染。若字体缺失导致显示不一致，必须如实声明渲染环境及残留风险。
