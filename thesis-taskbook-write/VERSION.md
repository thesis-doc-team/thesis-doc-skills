# Version

## 1.2.0 — 2026-10-30

- 并入统一**项目资产包布局与版本意识**（§0.2）：`deliverables/<文书类型>/` 归类、成品文件名带 `-vN`，重生成不覆盖历史版本，每版单独 record-use，历史版本永不删除。
- 统一加入**截图验证分析**环节（G 节）：截图 → 逐张分析 → 留痕汇报固定三步与红线；质量门禁 §5 与执行汇报模板同步固定字段（截图张数/实看张数/逐张结论/返工复检次数）。

## 1.1.0 — 2026-10-30

- 新增跨 Skill **项目级共享资产协议**：`project-assets/` 统一保存真实项目事实、带出处的文献库、周计划基线和变更/使用日志。
- 引入文献稳定 ID 与文书局部编号分离；后续开题报告等可复用核验文献而非反复检索、抄写。
- 引入共享周计划的 `draft/confirmed` 状态及显式变更原因，防止多个 Skill 静默覆盖。
- 新增 `scripts/project_assets.py`：初始化、读取状态、合并新增/更新、组合任务书输入、登记最终成品、临时目录创建及安全清理。
- 明确**中间文件生成后须删除**，但不删模板原件、源文档、共享资产与最终 Word；成功/失败都执行受控清理。
- 更新 SKILL、文献策略、集成协议、质量门禁、执行报告和使用说明；新增跨 Skill 合约及回归测试。
- 仍然**只负责任务书**，没有替用户改动其他独立 Skill 或官方 DOCX 模板。

## 1.0.0 — 2026-10-30

- 首次建立独立的毕业设计**任务书** Word 编写 Skill；不与开题报告或上游技术文档生成工作混淆。
- 以本轮塔里木大学**官方空白模板**为只读基线，内置一份 SHA-256 完全一致的原件副本。
- 从此前 4 份任务书和 V1–V3 审查反馈抽象“内容与形似”规则，禁止固化具体示例项目技术事实。
- 引入只读模板结构扫描、原位填充、不可变结构比对、引用/意见/周次门禁。
- 规定 CNKI/万方/维普及学术出版方优先，CSDN 技术辅助可用且须真实标注来源类型。
- 明确不强求页数、上下左右居中及真实 WPS 实测披露。
- 当前只支持这版官方模板 9×4 主表的自动填充；不同模板需要重新映射，不可强灌。
