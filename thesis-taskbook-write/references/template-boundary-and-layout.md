## 上下左右居中的标准

- 逐个可见单元格检查 `vertical_alignment == CENTER`、内部段落 `alignment == CENTER`；合并区域按合并后整体中心检查。
- 单元格标签与可填内容分别检查。若填入值所在段落有首行缩进、左/右缩进、制表符、额外空行，会产生**属性居中但视觉偏移**。可清理**可填段落**的这些噪声，不可私自更改模板边框/内边距/列宽来“硬凑”。
- 首五行高度已固定：长题目必须检查是否被剪裁。不能自动缩字号或调整行高；如模板和题目客观冲突，先告知用户。
- 不得宣称在 WPS 客户端中完成检查，除非真的打开 WPS 实测。兼容渲染器检查属于单独门槛。

## 官方固定条件

- “拟定工作进度：（以周为单位）”；“主要参考文献：（不少于10篇）”；“任务下达人意见：（不少于50字）”。
- “任务接受人意见：”与“任务接收人签名”在官方模板存在**接受 / 接收**字词差异。这是官方原文，不得擅自统一。
- 保留任务下达人签名、任务接收人签名、未签日期，以及 4 条学校注释。
- **不要求填充后的页数保持 3 页**：原模板空白页数只是空白状态。正文增多自然换页完全正常。
